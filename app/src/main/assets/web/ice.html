WebRTC ICE Servers

← Dashboard

STUN/TURN servers used by the WebRTC preview, as a JSON RTCIceServer[] array: [{"urls": ["turn:host:3478"], "username": "...", "credential": "..."}]. Both the browser and the phone use this list. Changes apply to the next WebRTC (re)connection — reload the dashboard to apply immediately. An empty array [] means LAN-only (host candidates).

Dynamic TURN

Fetch a short-lived TURN credential from a signaling server at connect time, and add it on top of the servers above. Use this when the TURN server hands out temporary (expiring) credentials rather than fixed ones. The phone fetches it and shares it with the browser automatically.
